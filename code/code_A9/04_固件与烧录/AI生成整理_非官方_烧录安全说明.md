# A9 固件与烧录安全说明

## 当前归档固件

以下文件来自项目资料目录，来源和授权未由本仓库独立确认；只能在私有协作范围内按 A9 型号核对使用。

- `A9固件_来源未确认/1.17.85`：A9 1.17.85，来源文件名带 20240711。
- `A9固件_来源未确认/1.17.86`：A9 1.17.86，日期 20260304，当前没有配套完整源码。

## 严禁混用

- `ACFlyK9Teach-20260422.hex` 不是 A9 固件。
- Wheeltec F570 BootLoader 不是 A9 固件。
- AC-RID 工具和固件不是 A9 主控固件。
- PX4、ArduPilot、Pixhawk 固件不能直接刷入 A9。

## 烧录前检查

1. 核对飞控型号是 A9。
2. 核对目标固件文件名和版本。
3. 保存当前固件、参数和日志。
4. 先拆掉螺旋桨。
5. 确认使用正确的 ST-LINK/SWD 或官方 USB Bootloader 流程。
6. 烧录后先连接 GCS PRO 检查版本、传感器和参数，不要立即起飞。
