- 基于博睿 A9 无人机的未知场景自动建模系统设计方案

  ## 1. 项目概述

  ### 1.1 项目背景

  本项目面向室内、厂房、通道等未知场景的三维信息采集与模型重建。系统以博睿 A9 无人机为飞行平台，搭载 RK3568 开发板、SLAMTEC RPLIDAR C1 二维激光雷达和奥比中光 Gemini 335Le 深度相机，在没有先验地图的情况下自主进入目标区域，完成环境探索、数据采集和场景建图。

  整个任务分为两轮。第一轮以快速获取场景结构为主，无人机边飞行边建立局部地图，并将关键图像、C1 扫描数据和轨迹通过 WiFi 传到电脑。电脑据此生成粗模型，分析未覆盖区域和建模质量较差的区域，规划第二轮精细拍摄路线。无人机执行补拍路线后，电脑融合两轮数据，生成完整的点云、网格和纹理模型。

  ### 1.2 建设目标

  系统需要完成以下功能：

  1. 无人机能够在未知场景中自主探索，并对障碍物进行实时检测和避让。
  2. RPLIDAR C1 与深度相机能够同步采集水平轮廓、三维几何和图像信息。
  3. RK3568 能够完成机载定位、局部建图、探索决策和数据管理。
  4. 采集数据能够通过 WiFi 稳定传输至电脑，并支持断点续传。
  5. 电脑能够根据第一轮数据生成场景粗模型。
  6. 电脑能够从粗模型中找出缺失区域，生成第二轮拍摄视点和飞行路线。
  7. 无人机能够执行精细采集路线，并根据现场障碍实时调整局部运动。
  8. 电脑能够输出彩色点云、三维网格、纹理模型、飞行轨迹和覆盖率报告。

  ## 2. 总体方案

  ### 2.1 系统组成

  系统由无人机端和电脑端两部分组成。

  无人机端负责实时任务。A9 完成飞行姿态控制和航点执行；RK3568 读取 RPLIDAR C1、深度相机和飞控状态，运行定位、局部建图、自主探索、避障和数据传输程序。

  电脑端负责全局任务。电脑接收第一轮采集数据，完成粗模型构建、覆盖分析和精细路线规划；第二轮任务完成后，再进行全局轨迹优化、点云融合、网格重建和纹理映射。

  ### 3.2 设备安装布局

  Gemini 335Le 和 RPLIDAR C1 固定在一块 130 × 100 × 2 mm 碳纤维安装板上。两台传感器之间保持刚性连接，任务期间不改变相对位置，保证相机与雷达之间的外参稳定。C1 水平安装在安装板中部偏后位置，旋转扫描平面不得被机架、RK3568 或线缆大面积遮挡。Gemini 335Le 安装在前缘并朝向无人机主要前进方向，拍摄画面中不得出现桨叶和大面积机体结构。通过调整 C1 前后位置，使传感器总成重心落在四个减震点围成区域的中心附近。

  传感器安装板通过四个对称布置的 M3 硅胶减震柱连接无人机机架，四孔中心距为 80 × 80 mm，安装板通孔直径为 3.2 mm。减震柱外径为 10～12 mm，橡胶高度为 8～10 mm，初始硬度选择 Shore A 35～40。整套传感器安装后，四个减震柱应均匀产生约 1～2 mm 静态压缩量。

  鲁班猫 2 LBC 主板、无线网卡和商品选项为“RK3586专用”的野火散热风扇安装在独立区域，不直接固定在传感器安装板上，避免散热风扇的振动传到相机和雷达。安装完成后记录整机重心，检查桨叶安全距离，并在 A9 中确认当前载荷下的飞行参数。

  ### 3.3 减震方案

  本项目采用“Gemini 335Le 与 RPLIDAR C1 刚性共架、传感器总成四点被动减震”的结构，不使用云台。云台主要用于补偿低频姿态变化，不能替代螺旋桨高频振动隔离；同时，相机单独随云台转动会使相机与雷达之间的坐标关系持续变化，增加定位、点云融合和避障处理的复杂度。精细拍摄所需的相机方向由 A9 调整机头姿态和拍摄视点实现。

  减震结构如下：

  ```mermaid
  flowchart TB
      CAM["Gemini 335Le"] --> PLATE["刚性传感器安装板"]
      LIDAR["RPLIDAR C1"] --> PLATE
      PLATE --> D1["减震点 1"]
      PLATE --> D2["减震点 2"]
      PLATE --> D3["减震点 3"]
      PLATE --> D4["减震点 4"]
      D1 --> FRAME["A9 无人机机架"]
      D2 --> FRAME
      D3 --> FRAME
      D4 --> FRAME
  ```

  四个工作减震柱采用相同规格并对称布置，另采购四个同规格减震柱作为备件。碳纤维板具有导电性，相机、雷达及其他金属安装位置使用 M3 尼龙绝缘垫片或隔离柱，避免电路焊点和导电外壳与碳板产生不需要的电气接触。

  减震结构设置两组对角布置的 M3 机械限位件，防止急停、大角度转向或落地冲击造成传感器安装板位移过大。限位螺钉穿过安装板上的 5.5～6 mm 通孔，正常状态下与孔壁保持 1～1.5 mm 间隙，上下保留约 2 mm 间隙。限位件在正常飞行时不与安装板接触，只在超过允许行程时起保护作用。

  0.5 m M12 CAT6a 电缆和 0.5 m M8 线缆在机架侧与传感器侧分别固定，中间保留平缓的 C 形柔性线段。线缆不得拉紧，也不得直接跨过减震结构形成刚性支撑，避免振动通过线缆绕过减震件传递到传感器。电缆弯曲范围不得进入桨叶区域或遮挡传感器视场。手动推动传感器板 1～2 mm 时，线缆不应产生明显回弹力。

  减震件选型以传感器、安装板和连接件的总质量为依据。减震系统固有频率按下式估算：

  ```text
  fn = 1 / (2π) × √(K / M)
  ```

  其中，`fn` 为减震系统固有频率，`K` 为四个减震件的总等效刚度，`M` 为传感器总成质量。固有频率应低于螺旋桨和电机产生的主要振动频率，同时避免过低造成飞行加减速时的大幅摆动。选定减震柱以 1～2 mm 静态压缩量为主要检查依据；正常飞行时传感器板相对机体位移应保持在约 1～2 mm 内，不能压到底或持续碰触限位件。

  装机前检查桨叶、电机和机架紧固状态，优先消除明显的振动源。A9 飞控原有减震结构保持不变，不与传感器减震板共用。

  ## 5. 第一轮自主探索

  ### 5.1 起飞前检查

  每次任务生成独立任务编号。RK3568 在起飞前检查以下项目：

  - A9 飞行模式、定位状态、电量和返航功能正常。
  - RPLIDAR C1 USB 连接正常，360°扫描数据连续且频率稳定。
  - Gemini 335Le 彩色图、深度图和帧率正常。
  - 相机、雷达与机体外参加载正确。
  - WiFi 状态正常，电脑能够收到心跳和设备状态。
  - RK3568 温度、内存和本地存储空间满足任务要求。

  检查通过后，A9 起飞并在场景入口处悬停，建立初始位置和局部地图。

  ### 5.2 环境感知与定位

  RPLIDAR C1 持续提供传感器安装高度上的 360°水平轮廓和障碍距离，Gemini 335Le 提供前向彩色图、深度图和三维表面信息。RK3568 将 C1 扫描匹配结果、RGB-D 运动估计以及 A9 的姿态、高度和速度信息融合，计算连续位姿。

  C1 的主要任务是提供水平面内的定位约束和周向障碍检测。三维场景结构、雷达扫描平面以上或以下的障碍由 Gemini 335Le 负责感知。局部地图同时维护二维水平占据栅格和前向三维局部点云，两种地图使用同一位姿和时间基准。

  无人机加速、制动或转向时会产生俯仰和横滚，C1 扫描平面会随之倾斜。RK3568 根据每帧扫描的时间戳读取对应的 A9 姿态，将扫描点从 `lidar` 坐标系转换到 `odom` 或 `map` 坐标系，再参与二维地图更新。姿态变化过大或时间对齐误差超过阈值的扫描帧不用于精确匹配。

  定位模块同时输出位姿和置信度。局部建图模块根据当前位姿更新障碍点、自由空间和未知空间，并删除超过局部范围的旧数据，使计算量保持稳定。

  ### 5.3 探索策略

  系统采用滚动探索方式，不在第一次进入场景时生成一条贯穿全场的路线。每个探索周期执行以下步骤：

  1. 更新局部地图。
  2. 找出自由空间与未知空间的边界。
  3. 生成可到达的候选目标。
  4. 根据新增可见区域、飞行距离、障碍距离和转向次数对目标评分。
  5. 选择最合适的目标并生成短航段。
  6. 将运动目标发送给 A9。
  7. 飞行过程中继续更新地图，必要时停止或调整路径。

  无人机以机头朝向主要运动方向。进入新区域前先完成转向，让 Gemini 335Le 对前方上下空间进行观察，再向前飞行。C1 只覆盖一个水平扫描平面，因此任务以低速、固定高度或少量离散高度层飞行为主，避免在缺少前向深度观察时高速侧飞、倒飞或快速升降。

  ### 5.4 局部避障

  局部避障使用 RPLIDAR C1 检测机体周围同一高度平面内的障碍，Gemini 335Le 负责前方近距离三维障碍以及高于或低于 C1 扫描平面的结构。系统根据当前速度计算制动距离，并在此基础上增加定位误差、测距误差和安全余量。只有 C1 和 Gemini 的有效视场共同确认可通行的区域，才标记为自由空间。

  当航线上出现新障碍时，系统依次采取以下动作：

  1. 降低飞行速度。
  2. 判断已知自由空间中是否存在可用绕行路线。
  3. 可以安全绕行时更新短航段。
  4. 无法确认绕行安全时悬停并重新规划。
  5. 多次规划失败时结束探索并返航。

  ### 5.5 图像和点云采集

  RK3568 不保存全部重复画面，而是根据位移、转角、图像清晰度、深度有效率和场景变化选择关键帧。关键帧由以下数据组成：

  - 彩色图像
  - 深度图像
  - 相机内参
  - 同时段 C1 二维激光扫描索引
  - 统一时间戳
  - 无人机位姿
  - 定位置信度
  - 图像和深度质量评分

  第一轮采集以覆盖场景结构为主，优先保证地图连续和主要表面可见。

  ### 5.6 第一轮结束条件

  出现下列任一情况时结束第一轮任务：

  - 可到达的未知区域已经探索完成。
  - 主要空间轮廓和可通行区域已经形成。
  - 剩余电量达到 A9 返航阈值。
  - 传感器、定位或机载计算状态异常。
  - 操作人员终止任务。

  无人机返航后继续传输尚未完成的原始数据，直到电脑确认文件完整。

  ## 6. WiFi 通信与数据管理

  ### 6.1 通信内容

  RK3568 与电脑之间建立两类逻辑通道：

  | 通道     | 内容                                         | 处理方式             |
  | -------- | -------------------------------------------- | -------------------- |
  | 状态通道 | 飞行状态、定位质量、任务进度、设备温度和故障 | 持续发送，优先级最高 |
  | 数据通道 | 图像、深度、C1 扫描、轨迹、地图和任务文件    | 分块传输，校验后确认 |

  探索过程中优先传输状态、轨迹、关键帧缩略图和降采样点云，使电脑能够同步生成粗模型。原始图像、完整深度图和 C1 扫描数据按带宽情况传输，未传完的数据保存在 RK3568 本地。

  ### 6.2 可靠传输

  每个文件记录任务编号、文件编号、时间戳、长度和校验值。大文件拆分为多个数据块，电脑确认已收到的数据块。WiFi 中断后，RK3568 继续完成当前安全动作并保存数据；连接恢复后，从未确认的数据块继续传输。

  电脑下发的路线文件包含任务编号、地图版本、路线版本、坐标系和整体校验值。RK3568 校验通过后才允许执行。

  ### 6.3 数据目录

  ```text
  mission_<任务编号>/
  ├── config/          # 任务参数和设备配置
  ├── calibration/     # 相机、雷达和机体标定数据
  ├── rgb/             # 彩色关键帧
  ├── depth/           # 深度关键帧
  ├── lidar/           # RPLIDAR C1 二维激光扫描
  ├── trajectory/      # 原始轨迹和优化轨迹
  ├── maps/            # 局部地图、粗模型和覆盖图
  ├── routes/          # 探索记录和精细采集路线
  ├── logs/            # 飞行、设备、温度和网络日志
  └── manifest.json    # 文件索引与校验信息
  ```

  ## 7. 电脑端粗建模

  ### 7.1 数据处理

  电脑收到第一轮数据后，按照以下顺序处理：

  1. 校验文件完整性和时间顺序。
  2. 剔除模糊图像、无效深度和雷达离群点。
  3. 根据机载轨迹将图像、深度和 C1 二维扫描数据变换到统一坐标系。
  4. 对相邻关键帧进行视觉和几何配准。
  5. 检测无人机重复经过的区域，建立回环约束。
  6. 优化完整轨迹，减小累计漂移。
  7. 使用 C1 扫描约束水平轮廓和轨迹，融合 Gemini 深度点生成降采样三维粗点云。
  8. 从粗点云中提取障碍区域、自由空间和未知区域。

  ### 7.2 粗模型内容

  粗模型主要服务于第二轮路线规划，应包含：

  - 场景主要轮廓
  - 障碍物和可通行空间
  - 第一轮飞行轨迹
  - 已拍摄表面和未覆盖表面
  - 点云稀疏区域
  - 遮挡区域
  - 低置信度区域

  电脑在第一轮飞行期间可以使用已回传的降采样数据增量更新粗模型；第一轮结束并收到完整数据后，再进行一次全局优化。

  ## 8. 精细拍摄路线规划

  ### 8.1 覆盖分析

  电脑将粗模型划分为若干表面区域，为每个区域计算以下指标：

  - 是否被彩色相机有效拍摄
  - 是否存在可靠的深度数据和对应的 C1 水平轮廓约束
  - 点云密度是否足够
  - 拍摄角度是否合适
  - 与相邻画面的重叠是否足够
  - 是否被其他物体遮挡

  未拍摄、点云稀疏、遮挡严重或配准质量较差的区域进入补拍列表。

  ### 8.2 视点生成

  系统根据目标表面的位置和朝向生成候选拍摄视点。每个视点包含无人机位置、机头方向、拍摄目标、建议停留时间和质量要求。

  候选视点应满足以下条件：

  - 位于粗模型确认的自由空间。
  - 与障碍物保持安全距离。
  - 目标位于 Gemini 335Le 的有效视场内。
  - 拍摄方向尽量接近目标表面法向。
  - 与相邻视点能够形成连续图像重叠。
  - A9 能够稳定到达并保持相应姿态。

  ### 8.3 航线生成

  电脑对候选视点进行筛选和排序，在保证覆盖质量的同时减少飞行距离和重复转向。路线生成后检查：

  - 航段是否位于已知自由空间。
  - 航段是否穿过障碍或模型空洞。
  - 转弯空间是否满足无人机运动要求。
  - 航点数量和格式是否符合 A9 接口要求。
  - 预计飞行时间是否保留足够返航余量。

  检查完成后生成路线文件，通过 WiFi 下发到 RK3568。

  ## 9. 第二轮精细采集

  ### 9.1 路线执行

  RK3568 校验路线版本和坐标系后，将航点依次提交给 A9。A9 负责飞行控制，RK3568 持续利用雷达和深度相机检查实际航路。

  电脑规划路线作为全局参考。现场出现人员、移动物体或其他临时障碍时，RK3568 优先保证局部飞行安全，可以减速、悬停或在已知自由空间内调整短航段。

  ### 9.2 拍摄控制

  无人机到达视点后，RK3568 判断当前位置、速度、姿态变化和定位质量。满足要求后，通过相机软件命令或 M8 触发信号记录精细关键帧。

  每次拍摄后立即检查：

  - 图像清晰度和曝光
  - 深度有效率
  - 激光数据完整性
  - 实际位置与计划视点偏差
  - 与相邻关键帧的重叠程度

  不合格视点加入补拍队列，在任务资源允许的情况下重新采集。

  ## 10. 精细三维建模

  第二轮数据回传完成后，电脑将两轮任务统一处理：

  1. 对彩色图、深度图和 C1 扫描数据进行质量筛选。
  2. 根据时间戳关联图像、深度、雷达和位姿。
  3. 将第二轮轨迹配准到第一轮粗模型。
  4. 增加相邻帧、跨航段和回环约束，进行全局轨迹优化。
  5. 融合有效深度点和激光点，生成完整点云。
  6. 删除离群点、动态物体和低置信度数据。
  7. 根据点云生成三角网格。
  8. 使用彩色关键帧进行纹理投影和颜色融合。
  9. 统计表面覆盖率、点云密度和未重建区域。

  最终输出内容包括：

  - 彩色点云
  - 三维网格模型
  - 纹理模型
  - 两轮飞行轨迹
  - 图像拍摄位置和方向
  - 场景覆盖图
  - 设备和任务日志
  - 建模质量报告

  ## 11. 主要运行参数

  下表作为初始调试参数，完成飞行和制动测试后再根据场地调整。

  | 参数             |                                          初始设置 |
  | ---------------- | ------------------------------------------------: |

  | 关键帧转角间隔   |                                          10°～20° |
  | 视点悬停时间     |                                          0.5～2 s |
  | 初始最小障碍距离 |                                             1.0 m |
  | 减震结构形式     |                                  四点对称被动减震 |

  | 减震孔中心距     |                                        80 × 80 mm |

  ```text
  安全距离 = 当前速度下的制动距离 + 定位误差 + 测距误差 + 安全余量
  ```

  ## 12. 异常处理

  | 异常情况            | 处理方式                                     |
  | ------------------- | -------------------------------------------- |
  | RPLIDAR C1 数据中断 | 降速并悬停，恢复失败后返航                   |
  | 深度相机数据中断    | 停止拍摄任务，保持雷达避障并返航             |
  | 定位置信度持续下降  | 停止深入未知区域，悬停并重新定位，失败后返航 |
  | WiFi 中断           | 保持机载任务安全运行并保存数据，重连后续传   |
  | RK3568 温度过高     | 降低处理负载并结束当前任务                   |
  | 本地存储空间不足    | 停止非关键数据记录并返航                     |
  | 现场与粗模型不一致  | 停止原航段，更新局部地图后重新规划           |
  | A9 低电量或状态异常 | 立即结束建模任务，执行 A9 返航策略           |
  | 路线文件校验失败    | 拒绝执行，等待电脑重新下发                   |

  A9 的低电量保护、失控保护、返航和人工接管始终具有最高优先级。RK3568 不直接控制电机，也不会在定位或环境感知不可靠时继续进入未知区域。

  ## 13. 开发与测试安排

  ### 13.1 单设备测试

  - 检查 Gemini 335Le 彩色图和深度图的连续输出。
  - 检查 RPLIDAR C1 的 USB 枚举、串口权限、扫描频率和长时间运行稳定性。
  - 检查 A9 状态读取、航点执行、悬停和返航指令。
  - 检查 WiFi 数据传输速度、丢包恢复和断点续传。
  - 检查 RK3568 满负载温度和风扇散热效果。

  ### 13.2 减震结构测试

  - 检查 130 × 100 × 2 mm 碳纤维安装板的刚度、四个 M3 减震柱受力及两组机械限位间隙。
  - 检查四个减震柱的静态压缩量是否均匀处于 1～2 mm 范围。
  - 检查 0.5 m M12 和 0.5 m M8 线缆的固定位置与 C 形柔性弯曲段，确认线缆没有旁路减震结构。
  - 分别在悬停、低速前飞和低速转向状态下采集图像、深度和 C1 扫描数据。
  - 检查 Shore A 35～40 减震柱条件下的图像清晰度、深度有效率和静态墙面点云厚度。
  - 检查 C1 扫描轮廓与 Gemini 深度点云截面的配准误差，确认传感器架没有持续共振或明显摆动。
  - 检查正常飞行时传感器板相对位移是否保持在约 1～2 mm，且没有压到底或碰触限位件。
  - 完成连续飞行后检查减震件、安装板和紧固位置是否松动或产生永久变形。

  ### 13.3 联合感知测试

  - 完成相机、雷达和机体坐标标定。
  - 检查 C1 扫描轮廓、Gemini 深度点云和彩色图的空间对齐。
  - 检查快速转向和直线运动时的数据时间对齐。
  - 检查定位轨迹连续性和重复路线的一致性。

  ### 13.4 自主探索测试

  - 在限定区域内进行低速直线和转向测试。
  - 验证未知边界提取和短航段规划。
  - 验证固定障碍、临时障碍和封闭路线下的处理方式。
  - 逐步扩大探索范围，记录任务完成时间和地图覆盖率。

  ### 13.5 完整闭环测试

  - 完成第一轮探索和数据回传。
  - 生成粗模型和第二轮采集路线。
  - 执行精细采集并完成补拍。
  - 输出点云、网格、纹理和质量报告。
  - 在同一场景重复执行，比较轨迹和模型的一致性。

  ## 15. 方案结论

  本系统以 A9 负责飞行控制，以 RK3568 负责机载感知和自主任务，以 RPLIDAR C1 提供水平 360°轮廓和周向避障信息，以 Gemini 335Le 提供前向三维几何与彩色图像，以 WiFi 完成无人机和电脑之间的数据交换。C1 与 Gemini 335Le 采用刚性共架和四点被动减震，RK3568 与散热风扇独立安装，系统不使用云台。电脑承担粗模型生成、精细路线规划和最终三维重建。

  项目实施后，无人机能够先在未知场景中自主完成一轮结构采集，电脑根据粗模型自动生成补拍路线，再由无人机完成精细数据采集，最终形成完整的三维点云和纹理模型。整个方案使用现有采购设备完成闭环，不依赖额外定位、通信或感知硬件。
