# QGdrone — 低空三维数字孪生系统

基于博睿 A9 无人机平台的自主三维采集与数字孪生系统。无人机搭载深度相机、激光雷达与机载计算模块，进入室内厂房、通道、施工现场等未知场景完成数据采集，数据回传后经三维重建（3DGS）生成数字孪生模型，并结合 AI 识别与分析服务于施工、巡检、救援和管理等场景。

## 项目定位

> 让无人机成为一个移动的低空数字化采集终端。

系统围绕"自动采集 → 三维建模 → 缺失检测 → 数字孪生"的链路构建：

- 无人机自主飞行与数据采集
- 视觉 / 激光定位与环境建图
- 点云、影像、三维模型生成
- AI 识别对象与检测状态
- 数字孪生平台与决策中心

### 任务流程

```
无人机起飞进入目标场景
        ↓
相机 / 激光雷达 / 飞控数据同步采集
        ↓
数据经 WiFi 回传电脑
        ↓
电脑根据点云 / 图像判断缺失区域
        ↓
三维重建（3DGS）生成数字孪生模型
```

## 系统组成

| 部分 | 负责小组 | 职责 |
| --- | --- | --- |
| 飞行平台（嵌入式） | 嵌入式 | 飞行姿态控制、航点执行、悬停、返航与人工接管 |
| 机载感知系统（嵌入式） | 嵌入式 | 传感器接入、时间同步、定位、建图、避障与数据传输 |
| 三维建模引擎 | AI 组 | 点云生成、3DGS 三维重建与模型优化 |
| AI 分析引擎 | AI 组 | 目标识别、状态检测与场景分析 |
| 数字孪生管理平台 | 工软 / 图形 | 三维展示、统计量、航线规划与项目日报 |

## 硬件方案

| 器件 | 型号 | 用途 |
| --- | --- | --- |
| 无人机 | 博睿 A9 飞控（STM32H743） | 姿态控制与航点执行 |
| 机载开发板 | 野火鲁班猫 2（RK3568，2GB + 32GB） | 定位、建图、避障、任务管理与数据传输 |
| 深度相机 | 奥比中光 ORBBEC Gemini 335Le | 彩色图、深度图与三维感知 |
| 激光雷达 | SLAMTEC RPLIDAR C1 | 水平 360° 扫描、定位约束与周向避障 |
| 无线网卡 | RTL8852BE/AE WiFi 6E | 机载端与电脑间的数据回传 |

传感器与机架之间采用刚性共架 + 四点被动减震，不使用云台。完整方案见 [docs/项目方案.md](docs/项目方案.md)。

## 核心软件

### 飞控源码（A9 / ACFLY）

A9 飞控基于 STM32H743VITx + FreeRTOS，仓库归档了多个固件源码版本，核心模块：

- `MeasurementSystem` 传感器测量与定位
- `ControlSystem` 姿态、位置与控制链路
- `Modes` 飞行模式与任务（含巡线模式 M35）
- `Communication` MAVLink、串口通信
- `Drivers` 外设驱动（含 SDI 视觉串口接收）

### VS V1 通信协议

AI/视觉端与嵌入式端之间的自定义二进制帧协议（`VS` 帧头），承载心跳、目标点、任务动作、扫描状态、危险告警与飞行状态等消息，支持 ACK 重发、去重与安全仲裁。协议设计约束 AI 端只能发送任务意图，解锁、起飞、姿态与电机控制始终由嵌入式端完成。

### 三维重建（3DGS）

AI 组以 3D Gaussian Splatting 为核心重建技术，结合 ORB-SLAM3 定位与 Open3D 点云处理，相关研究与路线见 [docs/plan](docs/plan) 与 [docs/reaserch](docs/reaserch)。

### A9 软件工具箱（a9tools）

面向 A9 学习的离线纯软件工具箱（Python），位于 `code/code_A9/06_开发环境/AI生成整理_非官方_A9软件工具/`：

- `simulate` — UDP MAVLink 遥测仿真器
- `mission-check` — 任务 JSON 预检查（坐标、围栏、高度、速度）
- `log-report` — 飞控日志 CSV 生成 HTML/PNG 报告
- `firmware-diff` — 源码目录 / HEX 对比
- `scan-demo` — AI 与嵌入式接口联调事件模拟
- `self-test` — pytest 单元测试
