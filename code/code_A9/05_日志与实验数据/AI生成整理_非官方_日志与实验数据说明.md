# AI生成整理_非官方_日志与实验数据说明

当前上传包没有可供团队复用的真实飞行日志或实验数据。此目录不是“数据已经整理完成”，而是预留位置；目前只放说明文件和后续目录备注，后续按项目测试逐步补充。

原始目录中包含博睿飞控日志分析软件和 `.aclog` 解读 SOP。软件本体未复制到 GitHub 上传包，仓库只保留说明和 SOP，避免把第三方可执行文件直接作为项目源码提交。

使用原则：

- 每次飞行或仿真都记录固件版本、参数版本和测试条件。
- 修改控制器、状态估计、模式或视觉接口后，优先比较日志。
- 重点检查姿态、位置、速度、电池、解锁状态、模式和异常标志。
- 后续加入示例日志前，需要先确认不包含个人隐私、无线网络密码或敏感地理信息。

## 后续建议的数据目录

- `原始日志_待清洗`：只放未经处理的项目日志，上传前确认是否适合协作。
- `清洗后日志`：删除敏感信息并注明固件、参数和测试条件。
- `实验记录`：记录测试目的、硬件、软件版本、步骤和结论。
