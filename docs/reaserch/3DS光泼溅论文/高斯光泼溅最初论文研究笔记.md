## 相关原理

### 内参的计算过程
* 项目种的计算地点：在 convert.py 调用 COLMAP 时，由 COLMAP 内部 SfM 流水线估计的
* **流程**
1. 初始化 — 从 EXIF 读取

COLMAP 读取图像的 EXIF 元数据，获取：
- 焦距（mm）
- 传感器尺寸（mm）
然后换算成像素单位：
```
fx_pixels = fx_mm * image_width / sensor_width_mm
fy_pixels = fy_mm * image_height / sensor_height_mm
cx = width / 2
cy = height / 2
```

2. convert.py 中的相机模型选择
`parser.add_argument("--camera", default="OPENCV", type=str)`
默认用 OPENCV 模型（含畸变参数：k1, k2, p1, p2），因为原始图像有镜头畸变。

3. Bundle Adjustment 联合优化
COLMAP 的 mapper 阶段用光束法平差（Bundle Adjustment） 同时优化：

```
优化变量：
├── 每张图像的外参 (R, T)
├── 每个相机的内参 (fx, fy, cx, cy, k1, k2, ...)
└── 每个 3D 点的坐标 (X, Y, Z)
```

优化目标：最小化重投影误差

  `err = ‖project(X, K, R, T) - detected_2d_point‖²`

这是一个大型非线性最小二乘问题，COLMAP 用 Ceres Solver 求解。
4. image_undistorter — 去畸变
BA 优化完后，convert.py:70 调用去畸变：
`colmap image_undistorter \
    --output_type COLMAP`
将带畸变的 OPENCV 模型转为 无畸变的 PINHOLE 模型：
- 去掉 k1, k2, p1, p2 畸变系数
- 重新计算等效的 fx, fy, cx, cy
- 对图像做去畸变校正
5. 最终写入 cameras.bin
写入的内参就是优化后的 fx, fy, cx, cy。
一句话总结
内参由 COLMAP 从 EXIF 初始化，再通过 Bundle Adjustment（联合优化所有相机位姿和 3D 点）精化，最后去畸变为 PINHOLE 模型输出。

### 四元数的含义
四元数四个数的含义
四元数 q = w + xi + yj + zk，其中 i, j, k 是虚数单位。
几何意义是绕某个轴旋转某个角度：
```
w = cos(θ/2)
x = nx * sin(θ/2)
y = ny * sin(θ/2)
z = nz * sin(θ/2)
其中 (nx, ny, nz) 是旋转轴方向，θ 是旋转角度。
```
举例：绕 z 轴旋转 90°：
θ = 90°,  θ/2 = 45°
w = cos(45°) = √2/2
x = 0 * sin(45°) = 0
y = 0 * sin(45°) = 0
z = 1 * sin(45°) = √2/2

q = [√2/2, 0, 0, √2/2]
为什么不用 4×4 齐次矩阵
其实用了，只是分两步：
```
COLMAP 存储：qvec(4个数) + tvec(3个数) = 7个数

相机构建：转为 world_view_transform(4×4) = 16个数
```

### 外参的计算过程
1. 初始位姿估计 — 基础矩阵 → 本质矩阵
从图像对之间的匹配点，COLMAP 估计基础矩阵 F：
匹配点对 (x₁, x₁') → 本质矩阵 E = K^T * F * K
对 E 做 SVD 分解，得到两种可能的 (R, T) 解，用三角化正性约束（3D 点必须在相机前方）选择正确解。
2. 增量式重建 — PnP
```
图像 A 已有位姿 + 3D 点
  ↓ 新图像 B 与 A 有匹配
对 B 中检测到的 2D 点，用 PnP 求解 B 的 (R, T)
  ↓
三角化新 3D 点
  ↓
合并到已有模型
```
COLMAP 用增量式 SfM：先建好一张图的位姿，逐步加入新图像，每加一张就用 PnP 估计位姿，再三角化新点。

* 深度相机直接给出每个像素的深度值 Z，结合内参就能算出 3D 坐标：
    * X = (u - cx) * Z / fx
    * Y = (v - cy) * Z / fy

## 需要注意的事项

### 旋转矩阵的定义和图形组的不一致

**R — 旋转矩阵**
```
类型:     np.ndarray
形状:     (3, 3)
数据类型: float32
含义:     相机坐标系 → 世界坐标系的旋转
约束:     R^T @ R = I, det(R) = +1
来源:     COLMAP: qvec2rotmat(qvec).T
          深度相机: 从位姿数据读取
坐标系:   COLMAP 约定（Y-down, Z-forward）
```
