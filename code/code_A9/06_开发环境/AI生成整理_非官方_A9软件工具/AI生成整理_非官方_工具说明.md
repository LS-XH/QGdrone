# A9 软件工具

本目录包含项目内的轻量协作工具源码，不包含 Python 虚拟环境和测试生成物。

## 工具

- 协议模拟器：构造和检查 A9 任务/协议数据。
- 示例任务检查：验证任务 JSON 示例。
- 日志报告：对示例 CSV/日志做基础报告。
- 源码比较：比较两个 A9 源码目录的文件差异。
- 单元测试：验证工具自身逻辑。

## 环境

建议使用 Python 3.12 创建虚拟环境，并安装本目录的 `requirements.txt`。

运行测试时请先进入本目录，再执行：

```powershell
python -m a9tools self-test
```

如果从仓库根目录执行，需要额外设置 `PYTHONPATH`，否则 Python 可能找不到 `a9tools` 包。
