## 一、总体技术方案：增量渲染

### 1. 核心思路

- **保留 3DGS 增量渲染部分**；上游不再用深度神经网络，改用**传统路径**（更快、更不吃算力），把数据交给 splat 做 3DGS 增量渲染。
- 目标：不太吃算力 + 比较好的渲染效果。
- 融合两项技术：**SplaTAM + realtime appearance**——两者不是合并成一个技术，而是"各取一块拼起来"：一边拿上游，一边拿下游。

### 2. 上游方案（SplaTAM）

- 上游技术 **SplaTAM** 输出：**点云图 + 避障图**。
- **避障图算法放无人机端算** → 可实现无人机自主避障；生成点云和位置的部分放到电脑 GPU 上算。
- 简化方式：把无人机位置直接丢给 splat，跳过深度学习网络（算力跟不上）。
- 两套可选方案：
  1. 用 **SplaTAM** 代替 splat 上游的算法；
  2. 直接从无人机端给位置。
- SplaTAM 说明：基于 3DGS 迭代优化的 SLAM（视觉 + 深度/激光同时运行），并做 GPU 加速，算得更快。

### 3. 下游（3DGS 增量输出）

- 把**全量输出改成增量输出**：不改模型架构、不加功能，只改输出方式（按帧输出增量）。

### 4. 坐标系问题（重点待研究）

- SFM 建出的 up 方向与实际 up 方向有出入（可能斜、角度不确定）；但 up 一旦定下就**固定不变**，不会每次增量漂移。
- 网站上有坐标转换功能：先标定水平，再吸附到网格——**需要研究是否需要做转换**。
- **镜面翻转问题**：渲染器里是镜面翻转（上下、左右都翻转），我们与图形组（Unity）的 up 定义不一致，属于数据统一问题。
  - 初步方案：给数据让他们统一，或我们这边先镜面处理再给图形组。
  - SFM 不用了之后会不会还出这类问题暂不确定（数据仍是 SFM 那套数据），待验证。

## 二、研究进展

### 1. 建图质量检测方向（本人）

- 已拉取 3DGS 原仓库，用手机拍视频成功渲染出 3D 建模图。
- 发现的问题：只想拍一个小物件时，周围其他物体也会被渲染出来。
- 后续研究目标：**定量检测模型哪里是空的、哪里需要多拍、以什么轨迹拍**。
- 已学习：相机模型、相机内外参、三维点映射到二维照片的公式。
- 涉及坐标系研究：拍摄角度、横竖屏会导致建模坐标与真实世界坐标不一致。

### 2. 3DGS 论文阅读与复现（思颖）

- 通读 3DGS 原始论文（"万恶之源"），弄清其演变与流程。
- 原版代码跑下来：精度不够、显存占用大、耗时长。
- **SpePR**（2025 顶会）：声称速度提升 8 倍、显存大幅降低；但复现失败（电脑死机两次），对该论文真实性存疑。
- 另一篇 S 开头顶会论文，还未跑。
- 输出物为 PLY 文件（与图片一起输出）。
- 下一步：研究如何让架构接收**带深度的照片**（当前输入照片无深度）。

### 3. 3DGS 改进论文（CV）

- 第一篇（精度优化）：整体 3DGS 架构不变，在高斯球上加入正则化、3D 渲染变形器、2D splats，使高斯球在更细层面拟合，提高精度；**已跑通，效果比原版好**（椅子示例）。
- 第二篇（表面提取/编辑）：3DGS 是一群高斯球、难以单独取出；该论文通过数学手段提取网格、划分成块，可整体拖出进行编辑。

## 三、硬件与建模场景

- 强哥要求可见光相机方案（如 80×20 之类），相机能否批下来未知。
- 深度相机（如 RealSense）约三四千元，能否批不确定；备选苹果手机激光雷达（12 Pro 起）。
- 讨论结论：先按**可见光**做，用现有技术提取深度/点云；实在不行再走深度相机。
- 备选方案：不强依赖强哥的相机，用自己的技术路线跑通，借大疆无人机（清晰度高）自己采集数据。

## 四、本次会议结论：无人机建模室外大场景

- **结论：由无人机建模室外的大场景，应用范围更广阔**（强哥需求多为室外：工地建模、救援等；无人机一般飞室外）。
- 建议流程：**先确定加什么功能（如工地进度对比、火场信息回传）→ 再针对场景建模 → 再衡量实时性必要性**（实时 / 近实时 / 离线）。
- 不同应用场景需要不同的模型设计（如室内小场景可用消费级深度相机；室外大场景对 GPU 算力要求高），避免需求不明确导致功能臃肿。

## 六、工作流（整体链路）

```
无人机（采集 + 避障）
   │  位置 / 图像
   ▼
SplaTAM（上游：点云 + 避障图，GPU 端算点云与位置）
   │
   ▼
3DGS 增量渲染（下游：全量输出 → 增量输出）
   │
   ▼
PLY 文件
   │
   ▼
图形组（Unity 渲染，需统一坐标系 / 镜面翻转）
```
