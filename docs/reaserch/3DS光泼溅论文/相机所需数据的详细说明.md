# Camera 类完整数据格式规格

## 1. 构造函数签名

```python
Camera(
    resolution,          # tuple: (width, height) 缩放后的分辨率
    colmap_id,           # int: COLMAP 内部 ID（可随便填）
    R,                   # np.ndarray, shape=(3,3), dtype=float32
    T,                   # np.ndarray, shape=(3,),  dtype=float32
    FoVx,                # float: 水平视场角（弧度）
    FoVy,                # float: 垂直视场角（弧度）
    depth_params,        # dict or None: 深度对齐参数
    image,               # PIL.Image: RGB 图像
    invdepthmap,         # np.ndarray or float: 逆深度图
    image_name,          # str: 图像文件名
    uid,                 # int: 序号（从0开始）
    trans,               # np.ndarray, shape=(3,): 平移偏移（默认 [0,0,0]）
    scale,               # float: 缩放因子（默认 1.0）
    data_device,         # str: "cuda" 或 "cpu"
    train_test_exp,      # bool: 是否使用 train/test 交替曝光
    is_test_dataset,     # bool: 是否是测试集
    is_test_view         # bool: 是否是测试视图
)
```

## 2. 逐字段详细规格

### R — 旋转矩阵

| 属性 | 值 |
|------|-----|
| 类型 | `np.ndarray` |
| 形状 | `(3, 3)` |
| 数据类型 | `float32` |
| 含义 | 相机坐标系 → 世界坐标系的旋转 |
| 约束 | `R^T @ R = I`, `det(R) = +1` |
| 来源 | COLMAP: `qvec2rotmat(qvec).T`；深度相机: 从位姿数据读取 |
| 坐标系 | COLMAP 约定（Y-down, Z-forward） |

### T — 平移向量

| 属性 | 值 |
|------|-----|
| 类型 | `np.ndarray` |
| 形状 | `(3,)` |
| 数据类型 | `float32` |
| 含义 | 相机在世界坐标系中的位置偏移 |
| 来源 | COLMAP: `extr.tvec`；深度相机: 从位姿数据读取 |

### FoVx, FoVy — 视场角

| 属性 | 值 |
|------|-----|
| 类型 | `float` |
| 单位 | 弧度（radian） |

转换公式：

```
正向（焦距 → FoV）:
    FovX = 2 * atan(width / (2 * fx))
    FovY = 2 * atan(height / (2 * fy))

反向（FoV → 焦距）:
    fx = width / (2 * tan(FovX / 2))
    fy = height / (2 * tan(FovY / 2))
```

### image — RGB 图像

| 属性 | 值 |
|------|-----|
| 类型 | `PIL.Image` |
| 格式 | RGB（3通道）或 RGBA（4通道） |

内部处理流程：

```
Image.open(image_path)
  → PILtoTorch() → resize 到 resolution
  → [C,H,W] tensor → /255.0 → clamp(0,1)
  → 存储为 self.original_image (torch.Tensor, shape=[3,H,W], device=cuda)
```

### invdepthmap — 逆深度图

| 属性 | 值 |
|------|-----|
| 类型 | `np.ndarray`（加载时）→ `torch.Tensor`（存储后） |
| 形状 | `(H, W)` 或 `(H, W, 1)` |
| 数据类型 | `float32` |
| 含义 | `1/Z`（深度的倒数） |

加载处理：

```python
# 16-bit 深度图
depth_map = cv2.imread(depth_path, -1).astype(np.float32) / 65536.0

# NeRF Synthetic 深度图
depth_map = cv2.imread(depth_path, -1).astype(np.float32) / 512.0
```

存储为：`self.invdepthmap` (torch.Tensor, shape=[1,H,W], device=cuda)

### depth_params — 深度对齐参数

```python
depth_params = {
    "scale":     float,   # 线性缩放因子（深度对齐）
    "offset":    float,   # 偏移量
    "med_scale": float    # 数据集中的中位缩放（用于过滤异常）
}
```

应用规则：

```python
# 对齐深度
invdepthmap = invdepthmap * scale + offset

# 过滤异常值
if scale < 0.2 * med_scale or scale > 5 * med_scale:
    depth_reliable = False
```

### resolution — 缩放后分辨率

```python
resolution = (target_width, target_height)
```

自动缩放规则（`camera_utils.py:43-61`）：

| `args.resolution` | 行为 |
|-------------------|------|
| `-1` | 宽 > 1600 时自动缩到 1600 |
| `1, 2, 4, 8` | 原图尺寸除以此数 |
| 其他值 | 指定目标宽度 |

## 3. 内部计算的矩阵

### world_view_transform（W2C 矩阵）

```python
# graphics_utils.py:38 getWorld2View2(R, T, trans, scale)
Rt = zeros(4, 4)
Rt[:3, :3] = R.T          # 注意：转置
Rt[:3, 3] = T
Rt[3, 3] = 1.0

# 应用 translate 和 scale
C2W = inv(Rt)
cam_center = (C2W[:3, 3] + trans) * scale
C2W[:3, 3] = cam_center
W2C = inv(C2W)

# 存储: shape=(4,4), 转置后存到 GPU
self.world_view_transform = torch.tensor(W2C).T.cuda()
```

### projection_matrix（投影矩阵）

```python
# graphics_utils.py:51 getProjectionMatrix(znear, zfar, fovX, fovY)
znear = 0.01
zfar = 100.0

P = zeros(4, 4)
P[0, 0] = 2 * znear / (right - left)      # fx
P[1, 1] = 2 * znear / (top - bottom)      # fy
P[0, 2] = (right + left) / (right - left) # cx 偏移
P[1, 2] = (top + bottom) / (top - bottom) # cy 偏移
P[3, 2] = 1.0                             # 透视投影
P[2, 2] = zfar / (zfar - znear)           # 深度映射
P[2, 3] = -(zfar * znear) / (zfar - znear)

# 存储: shape=(4,4), 转置后存到 GPU
self.projection_matrix = torch.tensor(P).T.cuda()
```

### full_proj_transform（MVP 矩阵）

```python
# Camera.__init__:88
self.full_proj_transform = W2C @ Projection
# shape=(4,4), 用于 CUDA 光栅化器将 3D 点投影到 2D 屏幕
```

### camera_center（相机世界坐标）

```python
# Camera.__init__:89
self.camera_center = inv(world_view_transform)[3, :3]
# shape=(3,), 用于 SH 颜色计算中的视角依赖
```

## 4. 数据流总结

```
你的深度相机数据
    │
    ├─ RGB 图像 → PIL.Image → resize → [3,H,W] tensor → self.original_image
    │
    ├─ 深度图 → np.float32 → resize → torch.Tensor [1,H,W] → self.invdepthmap
    │
    ├─ fx,fy,cx,cy → focal2fov() → FoVx, FoVy
    │
    ├─ R(3×3), T(3,) → getWorld2View2() → world_view_transform(4×4)
    │                                  → projection_matrix(4×4)
    │                                  → full_proj_transform(4×4)
    │                                  → camera_center(3,)
    │
    └─ image_name, uid → 用于索引和曝光映射
```

## 6. 坐标系约定

本项目使用 **COLMAP 坐标系**：

| 轴 | 方向 |
|----|------|
| X | 右 |
| Y | 下 |
| Z | 前（相机观察方向） |

如果你的深度相机使用其他坐标系（如 OpenCV 的 Z-forward 或 OpenGL 的 Y-up），需要做坐标系转换。

### 常见坐标系转换

```python
# OpenCV → COLMAP (Y-up, Z-back → Y-down, Z-forward)
R_colmap = R_opencv @ np.diag([1, -1, -1])

# OpenGL → COLMAP
R_colmap = R_opengl @ np.diag([1, -1, -1])
```

## 7. 深度图格式说明

### 文件格式

| 格式 | 位深 | 存储值 | 除数 |
|------|------|--------|------|
| PNG 16-bit | 16-bit unsigned | `depth_mm * 256` | `65536` |
| PNG 16-bit (NeRF) | 16-bit unsigned | `depth_mm * 512` | `512` |
| PNG 32-bit float | 32-bit float | 直接存储深度值 | `1.0` |
| NPY | 32-bit float | 直接存储深度值 | `1.0` |

### 逆深度转换

```python
# 从原始深度图转换为逆深度
depth = cv2.imread(depth_path, -1).astype(np.float32) / 65536.0
inv_depth = 1.0 / (depth + 1e-6)  # 避免除零

# 如果深度图已经是逆深度格式
inv_depth = cv2.imread(depth_path, -1).astype(np.float32) / 65536.0
```

## 8. 常见问题

### Q: 为什么 R 需要转置？

A: COLMAP 存储的是 `qvec2rotmat(qvec)`，这是一个 **world-to-camera** 旋转。本项目的 `getWorld2View2` 函数内部会再做一次转置来构建正确的 W2C 矩阵。

### Q: depth_params 可以为 None 吗？

A: 可以。如果深度图已经对齐到正确的尺度和偏移，可以传入 `None`。此时 `depth_reliable` 会根据深度图的值自动判断。

### Q: 如何处理深度相机的噪声？

A: 可以通过以下方式：
1. 设置 `depth_params` 中的 `scale` 和 `offset` 进行对齐
2. 在训练时通过 `depth_l1_weight` 控制深度正则化的权重
3. 对深度图进行预处理（如中值滤波）
